# 全身 IK の正解の動き（下書き）

全身 IK の点を動かしたときの「正解の動き」を、単純なリグの型ごとに決める。決めたものは、型ごとのテスト用リグとテストにする。
持ち物と角度・位置の制限は、いったん入れない（11-08 ユーザー指示）。

「正解」の列は、ユーザーが前に決めたこと（日付）か、決まっていないもの（**要決定**。今の案を書いておく）。

## 言葉

| 言葉 | 意味 |
|---|---|
| 重さ 1 の点 | 定義の重さが 1 の点。骨を引く |
| 軽い点 | 定義の重さが 0 で、乗る骨に重さ 1 の点が無い点。つかむと骨を引く（S88） |
| 向けるだけの点 | 定義の重さが 0 で、乗る骨に重さ 1 の点がある点。骨を回して点を目標へ向けるだけ（S28） |
| Free / Pin / Lock | 点の状態。Pin は「その場を維持する。ただし引っ張ることはできる」、Lock は動かない |
| 付け根の点 / 骨の上の点 | 骨の付け根（関節）に乗る点 / 付け根から離れた所に乗る点 |
| 届く | つかんだ点が目標へ行ける（間の骨を伸ばしきった長さの中） |

## どの型にも共通の決まり

| | 正解 | 出どころ |
|---|---|---|
| I1 | 離しても（キーを打ってクリップから当て直しても）、離す前の姿勢のまま | 11-07 |
| I2 | マウスを少し動かせば、姿勢も少しだけ変わる（2 つの答えの間を跳ばない） | 11-07・11-08 |
| I3 | 引いた距離に応じて、姿勢を元（キーの形）へ戻す力は掛けない | 10-28 |
| I4 | Lock の点は動かない | S88 |
| I5 | 骨・点の種類（道具かどうかなど）で決まりを変えない。決まりは点の重さ・状態・骨のつながりだけで決まる | 11-08 |
| I6 | つかんだ点は、届くなら目標へ行く | |

## リグの型

骨はどれも長さ 0.3m、角度・位置の制限なし。点は特に書かなければ付け根の点で重さ 1。根を留める定義（腰の Pin あり）と、留めない定義（S98）の両方で見る。

| 型 | 形 | 見ること |
|---|---|---|
| R1 | 一本の鎖 `R─A─B─C` | 先・途中・根を引く |
| R2 | 蝶番のある手足 `S─E(蝶番)─W` | 2 本の骨の IK、Pole |
| R3 | 枝分かれ `R─A─{B1─C1─D1, B2─C2─D2}`（枝の付け根 B1・B2 は骨 A に付く。人型の胸と両腕の形） | 片方の枝を引いたときのもう片方 |
| R4 | 骨の上の点 `A─B` の B の中ほどに点 P | 付け根でない点を引く・留める |
| R5 | 同じ骨に 2 点 `A─B`、B に付け根の点と骨の上の点 Q | 同じ骨の点どうし |
| R6 | 軽い点の鎖 `S─E─W`、S・E は重さ 0、W だけ重さ 1 | 軽い点を引く |
| R7 | 向けるだけの点 `R─A─B`、A に重さ 1 の付け根の点と重さ 0 の点 D | 向けるだけの点を引く |
| R8 | 軸まわりにしか回らない骨 `R─P─K(軸)─A─B`（K は角度制限で 2 軸を回さない骨。親 P は根でない骨） | 軸の骨をはさむ鎖 |

## 決めたこと（11-08）

1. **離れの変わらない 2 点（1-4・1-6・2-3・4-1・5-1）**: つかんだ点を届かせ、Pin の点は必要な分だけ引く。Pin の「その場を維持する。ただし引っ張ることはできる」をそのまま当てはめる
2. **Free の子の骨の向き（1-7・3-3）**: 親に対する向きのまま（FK）
3. **骨の上の点（4-1）**: 骨が回るだけで届かない分は、付け根の Pin も引かれる

ほかに足したい型・場合があれば足す。

## 今の結果（11-08）

テストは `Tests/Editor/FullBodyCaseTests.cs`（56 件。根を留める定義・留めない定義の両方）。マウスを 20 回に分けて動かし、毎回キーの姿勢から解き直す（窓と同じ）。
「跳ばない」（I2）は、どの骨も 1 回でマウスの動きの 4 倍 + 5mm より大きく動かないこと。Pin が「留まる」は 5mm 以内。
I1 は全部の場合で、最後に窓で離したときと同じ手順（引かれた Pin・Lock の点を骨の今の場所へ付け直し、つかむのをやめ、今の姿勢をキーにする）で解き直し、骨が 1mm・0.5° より変わらないこと。
I3 は伸びきる場合（1-3・1-8・3-2）で、伸びきった後にさらに引いても伸びきったまま（5mm より縮まない。キーの曲がりへ戻らない）こと。I4〜I6 は場合ごとの正解の中で見ている。

全部通る（初めは 1-3・1-4・1-5・2-2・2-3・3-2・8-1 が通らなかった。11-08 に直した。下の表）。

### 直したこと（11-08）

| | 原因 | 直し方 |
|---|---|---|
| 1-4・2-3 | 離れの変わらない 2 点を、「つかんだ点の骨の上の点」と「つかんだ骨にぶら下がる骨の付け根の点」だけで見分けていた（逆向きの、つかんだ点が付け根の点で Pin の点が親の骨にある場合を数えず、根を留めない定義では数えなかった）。Pin の点は伸びきったときだけ引き、近すぎるときはソルバー任せで、Pin の点が最小の所から 7cm ずれて押され、最後に別の答えへ跳んだ | 「同じ骨の上」か「付け根の点は親の骨に付く」で見分け（RigidPair）、どちら向きでも、どちらの定義でも、Pin の点をつかんだ点から決まった離れの所へ最小だけ運ぶ（遠すぎても近すぎても） |
| 1-5 | Lock の点と離れの変わらない点を引くと、ソルバーが Lock の点と取り合って骨を回しきれず、つかんだ点が元の場所に残った | つかんだ点の目標を、Lock の点から決まった離れの球の上で一番近い所にして解く（ClampToLock） |
| 1-3 | 伸ばした姿勢から解き始める処理（StraightenPath）が、道の上の Pin の点の骨を根（腰）とみなし、その骨だけを運んで、親（根）を元の場所に残した。ソルバーは解き始めの姿勢で骨の長さを測るので、伸びた骨のまま解き、Pin の点が動かなかった | Pin の点の骨の根の方の骨も、一緒に運ぶ |
| 3-2 | 枝が骨 1 本で、最初から伸びきっていた（テストの置き方の誤り。B2 は骨 A に付くので、B2─C2 の離れは変わらない） | 枝を骨 2 本にした（3-2）。骨 1 本の形は 3-4 に分けた |
| 3-4（留める） | 道の外の Pin の点を運ぶ量（BranchShifts）を、Pin の点を外して解いた姿勢で測っていた。その姿勢では体がキーの形へ戻って起き上がるので、運ぶ量が多すぎ（マウス 4cm に 15cm）、引かれ始めの 1 回で跳んだ | その量の何割で届くかを探し、届く一番小さい割合だけ運ぶ（LeastBranchScale）。離れの変わらない Pin の点の運ぶ量は絞らない |
| 3-4（留めない） | 点の間の道の外にぶら下がる根の側の骨（R）の向きを決める決まりが無く、反復の途中の形で残った。届かなくなったところで 1 回 45° 回った | 根を留めない定義で、点の掛かった骨が 2 本以上なら、それらをつなぐ木の一番上の骨より根の側の骨を、一番上の骨に付けて元の向きのまま動かす（CarryRootSide。11-08 ユーザー決定「A に付いて回る」）。点が 1 つだけなら今までどおり（1-8） |
| 2-2 | Pole（手足の付け根と先を結ぶ軸まわりに回す。SnapPole）は、Pole の骨にほかの点があると Pole にしなかった（膝の点のように関節の場所を決める点を除くため）。付け根の S の点も除かれ、Pole がふつうに骨 S を向けて Pin の W を引いた | 除くのは、蝶番の骨の点と、Pole の骨の付け根から離れた点だけにする（付け根の点は軸の端にあり、関節の場所を決めない） |
| 8-1 | 向けきれない分を親が回して向ける処理（AimWithParent）は、動かせない点で決まる軸の骨（axisLock。鎖骨・持ち物の握り）だけに効き、角度制限で 2 軸を回さないにした骨は別の扱いだった（向けたあと仕上げで制限に戻され、36° 残った）。テストのリグは K の親が根の骨で、根は回さない決まりにも当たっていた | 2 軸を回さない骨も、残りの 1 軸まわりにだけ回る骨（axisLock）にする。リグは K の親を根でない骨にした |
