Pose and animate characters right inside the Unity Editor

Lilium Motion Editor is a free, open-source editor extension for keyframe animation. Pose with FK and a Burst-powered full-body IK, layer edits without touching the source, and bake clips your game can play — on characters of any proportions.

Features

Everything for keyframing, in one window

Open a character prefab, pose it, set keys, save. No round trip to a DCC tool.

Editing rig

You pose through a rig that duplicates the character's bones. Clips store rig values, so one clip works on characters with different body proportions.

Full-body IK (Burst)

Drag a hand or a foot and the whole body follows. Mark points Free, Pin or Lock; feet roll on the floor instead of sinking into it.

Non-destructive layers

Stack Override and Additive layers on top of a clip — even motion capture — and limit them with channel masks. The source stays untouched.

Timeline & curves

Curve, linear or constant interpolation per segment, a stepped preview for blocking, cycle keys for seamless loops, and a curve editor.

Bakes to Humanoid

Save bakes a Humanoid clip for your game, carrying Animation Rigging weights and extra properties so it plays back the same.

Scriptable & AI-ready

Author poses without the window: full-body IK points as JSON, a motion linter for foot sliding and pops, and Unity CLI commands.

Full-body IK

Grab a point. The body follows.

Every joint, foot and hand is a point you can drag. The solver runs on Burst, so posing stays interactive even with many points pinned.

  • Free, Pin, Lock — choose which points move with the body and which stay where you put them.
  • Floor Clamp — the foot behaves like a rigid box pressed onto the floor: it rolls from toe to heel and slides, never sinks.
  • FK when you need it — click a limb to rotate its bone; pinned points further down the chain rotate with it.
Layer stack

Edit on top, never in place

A pose is built by a stack of layers — editing rig, full-body IK, Override and Additive layers, display. For each layer you choose what to show, where keys are written and what your handles grab.

  • Override & Additive — fix captured or generated motion without destroying it.
  • Channel masks — limit a layer to body parts or property patterns; import from an Avatar Mask.
  • Properties — key blend shapes, visibility and component values next to the pose.
Optional · Kimodo

Let a motion model fill the in-betweens

With the optional Kimodo sample, NVIDIA's Kimodo motion model generates the motion between your keys from a text prompt. The result comes back as an Override that keeps your keyed poses — switch it on and off, or bake it.

  • Your keys stay — generated frames only fill the ranges you pick.
  • Guided setup — the Kimodo panel walks you through installing it with Docker or Python.
  • Not bundled — you download Kimodo and its weights yourself, under their licenses.

Get started

Install

In Unity, open Window > Package Manager, choose + > Install package from git URL... and enter:

https://github.com/you-ri/LiliumMotionEditor.git?path=/Packages/jp.lilium.motioneditor
  1. Open Window > Lilium Motion Editor > Motion Editor.
  2. Pick a character prefab that has an Animator.
  3. Pose it, set keys, and save to a clip.

Want something to try right away? Import the Demo sample from the package's page in the Package Manager — it includes two characters and a set of hand poses.

Requirements

Unity 6000.0 or later
On 6000.6+, the bone handles plug into Unity's tool system and the Tools overlay.
Burst & Mathematics
Installed automatically as dependencies.
Animation Rigging — optional
Edit Animation Rigging values when installed.
Timeline — optional
Edit clips in place on a Timeline when installed.
