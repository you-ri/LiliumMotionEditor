Lilium Motion Editor
機能 使い方 インストール English GitHub

キャラクターのモーションを、
Unity エディタの中で作る

Lilium Motion Editor は、キーフレームでモーションを作るための無料・オープンソースのエディタ拡張です。 FK と Burst で動く全身 IK でポーズを付け、元のデータを壊さずにレイヤーで直し、 ゲームでそのまま再生できるクリップに焼きます。体型の違うキャラでも同じクリップを使えます。

Package Manager で入れる GitHub で見る
Unity 6000.0 以降MIT ライセンス画面は English / 日本語
Features

キーを打つための道具が、1 つの窓にそろう

キャラクターの prefab を開いて、ポーズを付け、キーを打ち、保存する。DCC ツールとの行き来はいりません。

編集用リグ

キャラの骨を複製したリグを通してポーズを付けます。クリップにはリグの値が入るので、体型の違うキャラでも同じクリップを使い回せます。

全身 IK（Burst）

手や足をつかんで動かすと、体全体が付いてきます。点ごとに Free・Pin・Lock を選べ、足は床に埋まらずに床の上を転がります。

壊さずに直すレイヤー

元のクリップ（モーションキャプチャーでも）の上に Override・Additive の段を重ね、マスクで効く範囲を絞れます。元のデータはそのままです。

タイムラインとカーブ

キーの間ごとにカーブ・直線・一定の補間を選べます。ブロッキング用のコマ送り表示、ループの継ぎ目を合わせるサイクルキー、カーブエディタもあります。

Humanoid クリップへ焼く

保存すると、ゲーム用の Humanoid クリップを焼きます。Animation Rigging の重みや任意のプロパティも入るので、ゲームでも同じ見た目で再生されます。

スクリプトや AI からも

窓を開かずにポーズを作れます。全身 IK の点を JSON で読み書きし、足の滑りや跳ねを検査し、Unity CLI のコマンドから動かせます。

Full-body IK

点をつかめば、体が付いてくる

関節・足・手は、どれもつかんで動かせる点です。解くのは Burst なので、たくさんの点を固定していても軽く動きます。

  • Free・Pin・Lock — 体と一緒に動く点と、置いた場所に残る点を選べます。
  • Floor Clamp — 足を硬い箱として床に押し当てるように動かします。つま先から踵へ転がり、横へは滑り、床には潜りません。
  • FK も使える — 手足を押すとその骨を回せます。その先の固定している点も一緒に回ります。
Layer stack

上に重ねて直す。元は書き換えない

ポーズは段の重なり（編集用リグ・全身 IK・Override や Additive の段・表示）で作られます。段ごとに、見せるか・キーをどこへ書くか・ハンドルでどこをつかむかを選べます。

  • Override・Additive — キャプチャーや生成した動きを、壊さずに上から直せます。
  • マスク — 段の効く範囲を部位やプロパティの決まりで絞れます。Avatar Mask から読み込めます。
  • プロパティ — ブレンドシェイプ・表示の ON/OFF・コンポーネントの値も、ポーズと並べてキーを打てます。
Optional · Kimodo

キーの間は、モーション生成モデルに任せる

オプションの Kimodo サンプルを入れると、NVIDIA のモーション生成モデル Kimodo が、打ったキーの間の動きを文章から作ります。 結果は、キーの姿勢を残したまま Override として入ります。ON/OFF を切り替えたり、焼き込んだりできます。

  • キーはそのまま — 作るのは選んだ範囲のキーの間だけです。
  • 入れ方を案内 — Kimodo のパネルが、Docker か Python で入れる手順を案内します。
  • 同梱はしない — Kimodo と重みは、ライセンスを確かめたうえで各自でダウンロードします。
How it fits

手元の prefab から、ゲームで再生するクリップまで

今あるキャラクターの prefab をそのまま使います。保存するのはリグの値の編集用クリップで、ゲームが使うのはそこから焼いた Humanoid クリップです。

キャラクターの prefabAnimator の付いた、今あるキャラ。
→
編集用リグFK・2 ボーン IK・全身 IK・Animation Rigging の値でポーズを付ける。
→
編集用クリップリグの値・段・プロパティ。体型の違うキャラでも使い回せる。
→
Humanoid クリップ保存のときに焼く。Animator や Timeline でそのまま使える。
Get started

インストール

Unity で Window > Package Manager を開き、+ > Install package from git URL... に次を入力します。

https://github.com/you-ri/LiliumMotionEditor.git?path=/Packages/jp.lilium.motioneditor
  1. Window > Lilium Motion Editor > Motion Editor を開きます。
  2. Animator の付いたキャラクターの prefab を選びます。
  3. ポーズを付けてキーを打ち、クリップへ保存します。

すぐ試したいときは、Package Manager でこのパッケージを選び、Samples の Demo をインポートしてください。キャラクター 2 体と手の形の姿勢が入っています。

動かすのに必要なもの

Unity 6000.0 以降
6000.6 以降では、骨のハンドルが Unity のツールの仕組みに乗り、Tools オーバーレイから道具を選べます。
Burst・Mathematics
パッケージの依存として自動で入ります。
Animation Rigging — 任意
入っていると、Animation Rigging の値を編集できます。
Timeline — 任意
入っていると、Timeline のクリップをその場で編集できます。
