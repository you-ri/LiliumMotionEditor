# Changelog

## [Unreleased]

### Added

- リグ定義の全身 IK の点に、床との当たりに使う球の半径（`radius`。体の大きさに対する割合）を追加した。標準の定義では足裏の点（踵・足裏の中心・小指側・つま先の先）に 0.02 を入れ、基準姿勢で球の下の端が地面に着く高さに置きます。Floor Clamp・モーションの検査（床・接地）・取り込みで足を床に留める処理は、球の下の端で床と比べます。モーションエディタとリグエディタでは、半径のある点に球の輪を描きます。Floor Clamp で足の点（足首・足裏の点）をつかんで動かすときは、足を、接地の点を頂点にした硬い箱として現実の箱を床に押し当てたように動かします。床に当たった点は滑らずにそこを支点に転がり（つま先から着けば踵が下り、面で着いた所で止まる）、横へは床の上を滑り、持ち上げると足の形と向きのまま床を離れます。Locked の点は動かない支点になり、つま先はつま先の付け根で曲がります。足の点をつかんで動かす間は、同じ足の Pin の点も足と一緒に動き、離したときに今の場所で Pin のまま付け直します。足裏の点の場所が変わるので、焼いた Humanoid 版は一度「焼き直しが要る」になります。

- Override の段にマスク（`Channel Mask`）を付けられるようにした。`Create > Lilium Motion Editor > Channel Mask` で作り、部位（Avatar Mask と同じ区分）と、パス・プロパティの決まり（`*` と `?` を使える）で効く範囲を決めます。マスクの外は重ねず、その段が書き出し先のときはキーも打ちません。マスクの外の骨や IK はつかめません。

- 任意のプロパティ（ブレンドシェイプ・表示の ON/OFF・コンポーネントの数値）を Override の段で重ねられるようにした。Properties パネルで打つキーは書き出し先の段へ入ります。Additive の段で足し合わせるのは小数の値（ブレンドシェイプなど）だけで、ON/OFF・整数・Transform の値は置き換えます。焼き・統合にも段を重ねた値が入ります。

- マスクのインスペクタに Avatar Mask の読み込み・書き出しを追加した。読み込みでは骨のパスをキャラの Humanoid の骨へ引き当てます。書き出すのは部位だけで、移らない決まりは数を知らせます。

- 既定のマスク（Body・Upper Body・Hands・Face）を同梱した。Stacker の組の一覧にも「名前 (Mask)」で出て、そのマスクの範囲でキーを打ったりずらしたりできます。

- 窓を開かずに姿勢を作ってキーを打つ `PoseSession` を追加した。描かない世界でキャラと編集用リグを作り、窓と同じ段の並び・同じ書き方でクリップへキーを打ち、Humanoid 版へ焼けます。スクリプトや AI から使う口です。

- 全身 IK の点の場所で姿勢を読み書きする `PoseDocument` を追加した。点ごとの状態（Free / Pin / Locked）・体から見た位置（メートル）・向きを JSON にします。体の大きさの違うキャラへは `Rescale` で合わせます。

- モーションの検査 `MotionLint` を追加した。足の滑り・床へのめり込み・筋肉の範囲の超え・1 フレームだけの跳ね・キーの間の大きすぎる回転を、フレームの範囲つきで出します。窓には Lint のパネル（既定は隠れている）を足しました。Check で調べ、行を押すとそのフレームへ移り、Copy で結果を JSON でクリップボードへ写します。

- JSON の要求でモーションエディタを動かす `MotionEditorCommands` を追加した。開く・状態を見る・姿勢を読む／書く・検査・焼く・保存・画像を撮る・取り込む・閉じる、を 1 つずつ、または並べて送れます。`-executeMethod Lilium.MotionEditorCommands.RunFromCommandLine` でバッチから、`com.unity.pipeline` があれば Unity CLI の `motion_*` コマンドからも呼べます。

- 姿勢を 4 方向（前・右・上は平行投影、斜めは透視）から画像に書き出す `PoseCapture` を追加した。

- 外で作った Humanoid のクリップを、元のクリップに重ねる Override として取り込めるようにした（`PoseSession.ImportOverride`）。元との差分にしてキーを間引きます。足を床に付ける指定をすると、足が滑っている区間だけ脚を解き直します。

- サイクルキーを追加した。最後のキーをいつも先頭のキーと同じ姿勢に保ち、ループの継ぎ目で止まらないようにします。タイムラインで最後のキーを右クリックして「サイクルキー」を入れます。

- 全身 IK の足の点を、足のリグと同じ 5 点にした。足首・踵・足裏の中心（`SoleBall`）・小指側（`LittleToeSide`）・つま先の先です。足裏の中心を回すとそこを支点に足が回り、小指側で足を傾けたりひねったりできます。

- 全身 IK に膝の Pole（`KneePole`）を追加した。足首を動かさずに、膝の向きだけを変えられます。

- 全身 IK の点に「引く強さ」（`pullStrength`）を追加した。0 の点はほかの骨を引かず、骨を目標の方へ向けるだけになります。リグ定義の点の一覧で決めます。

- リグ定義の点に、線でつなぐ相手（`link`）と、置き場所の基準 `SoleBall`・`LittleToeSide`・`Knee` を追加した。

- Controller のパネルに Reset ボタンを追加した。選んでいる物すべてを基準姿勢へ戻し、今のフレームにキーを打ちます。

- 全身 IK の点をつなぐ線を押すと、線に当たる骨の FK を選んで動かせるようにした。点をつかむ間にメッシュを押したときも、その骨の FK を選びます（今までは関節の点を選んでいました）。回転のギズモ・Spinner・数値欄で回すと、その骨より先の Pin の点も骨と一緒に回ります（Locked の点はその場に残り、Free の点は体に付いて動きます）。

- 表示域でメッシュにマウスを乗せると、押したら選ぶ物（骨・IK など。全身 IK の点をつかむ間は骨の FK の線）を強調するようにした。

- Controller のパネルに Floor Clamp のチェックボックスを追加した。入れると、全身 IK の点を動かすときに床（ワールドの Y = 0）より下へ置きません。床より下へ動かした分は、床の上の横の動きになります。いくつか選んで動かすときは、選んでいる点をひとかたまりとして扱い、一番低い点が床に着いたところでかたまり全体が止まって床の上を滑ります。全身 IK の中でも、足の接地の点（足首・踵・足裏の中心・小指側・つま先の先）を床との当たりとして解き、床より下へ潜らせません。床に当たった足は、当たった所を支点に転がります（足首を Pin にして腰を下げても、つま先が床に埋まらずに足が床に沿います）。足首の向きを固定していても、床に当たった分は回ります（点の向きの値は変えません）。操作のときだけ効き、点ごと・クリップには保存しません。

- 表示域で、Shift で選択に足し、Ctrl（Mac は Command）で子階層をまとめて選べるようにした。

- リグ定義の全身 IK の点に、ずれの向きを混ぜる相手の骨（`blendBone`）と割合（`blend`）を追加した。点のずれを、乗る骨ともう 1 本の骨の向きの間で回します。肘の Pole など、引く強さ 0 の点で使えます。

- Motion Editor と Motion Scene の窓で Ctrl+A（Edit > Select All）を押すと、今つかめる物を全部選ぶようにした。全身 IK の点をつかんでいるときは全部の点を選びます。

### Changed

- 姿勢のコピー・貼り付けを、C / V から Ctrl+C / Ctrl+V（Edit > Copy / Paste）に変えた。タイムラインのキー欄にフォーカスがあるときは、今までどおり選んだキーのコピー・貼り付けです。キーは Edit > Shortcuts の `Main Menu/Edit/Copy`・`Paste`・`Select All` で変えられます。Motion Scene の窓では、キャラを編集している間だけ姿勢のコピー・貼り付け・全選択になり、編集していなければ Scene ビューのまま（GameObject のコピーなど）です。

- 全身 IK の点を 1 つ選んで回すと、その骨より先の Pin・Locked の点も、選んだ点を中心に一緒に回るようにした（以前は置いた場所のまま残り、腕だけが曲がっていました）。

- リグ定義の全身 IK の点の置き場所を、部位ごとの基準（踵・つま先・膝・目など 9 種）から、1 つの式（基準の骨 `origin`・先の骨 `toward`・割合 `along`・横 `across`・残す成分 `axes`・地面 `ground`・骨が無いときの向き `fallback`）にした。既定の点の名前と場所は変わりません。

- つま先の骨が無いキャラには足の点（踵・足裏の中心・小指側・つま先の先）を、指の骨が無いキャラには手のひらの点を作らないようにした。

- 顔の前の点の高さを、目の骨から求めるようにした。目の骨が無いキャラは決まった高さです（頭のメッシュから見積もるのはやめました）。

- 肘・膝の曲がる向きをリグ定義の骨の項目（`hinge`・`bendDirection`）に、接地の点を点の項目（`contact`）に持つようにした。定義が変わるので、焼いた Humanoid 版は一度「焼き直しが要る」になります。

- リグ定義の版と、古い版の定義の読み替えをやめた（後方互換は保ちません）。古い定義のアセットは、インスペクタの「既定に戻す」で作り直してください。

- Transform のパネルの名前を Controller にした。中身と操作、パネルの置き場所・開閉はそのままです。

- Stacker の Loop のトグルを、サイクルキーの付け外しにした。前の Loop を入れてあったクリップは、開くとサイクルキーが付いています。

- リグ定義の版を 6 に上げた（後方互換は保たない）。版 5 までの定義は全身 IK の点の一覧を作り直すので、追加した点と、つま先の点（`LeftToes`・`RightToes`）のキーは当たらなくなります。

- 既定の定義で、向きの点（`HipsDirection` など）の引く強さを 0 にした。既定の定義を使うクリップで向きの点を固定してある所は、解いた姿勢が変わります。自分で作った定義は 1 のままです。

- 全身 IK の顔の前の点（`HeadDirection`）を目の高さに置くようにした。

- 全身 IK の膝の Pole（`KneePole`）を、太ももと脛の向きの間に置くようにした。膝を曲げても、Pole が膝の真上などの極端な場所へ回らず、膝の外側に出ます。リグ定義の版を 7 に上げ、版 6 の定義は膝の Pole の設定だけを直します。

- 踵を足首の真下へ寄せた。踵を支点に回すときに、足首が大きく振れなくなります。

- 足の転がしの支点を、体の前ではなく足の向きに並べるようにした。

- 全身 IK の点を回転のギズモで回しても、ほかの固定した点は一緒に回らないようにした。

- 全身 IK の点の枠選択で、選択に足すのを Shift だけにした。Ctrl は子階層を選びます。

- パネルのアクセントの色を、Unity のエディタのテーマの選択の色にした。

- Controller のパネルから Mirror ボタンを外した。

- Layers の段と段の間の矢印を Material Icons にした。逆に通れるかの説明は矢印のツールチップに移しました。

- タイムラインの全身 IK の点のトラックで、キーの間の矢印とフレーム数を、その間の点の状態（Free / Pin / Locked）の色にした。状態は次のキーまで引き継ぐので、前のキーの箱と同じ色です。

- `PreviewWindow.EndCurveEdit` を `AfterClipEdit` にした。クリップを書き換えた後の後始末を、ほかの編集と同じ 1 本で行います。`HumanoidOutput` の `GetOutputPath`・`WriteLink`・`GetStatus` の段になったオーバーロードは、既定の引数を持つ 1 本ずつにまとめました。`AnimBank.Entry` と `PoseBank.Entry` は同じ形なので `BankEntry` 1 つにしました。

### Fixed

- 頭の点が向きも固定しているフレームで、顔の前の点（`HeadDirection`）を動かしても頭がまったく向かなかったのを直した。全身 IK の点を 1 つだけつかんで動かす（丸・移動ギズモ・Spinner）と、同じ骨の上の別の場所にある点の向きの固定を外し、2 点で骨の向きを決め直します。外した点には次のキーで向きの固定の強さ 0 を打ちます。Locked の点の向きの固定は外しません。

- 全身 IK の点をいくつか選んでまとめて回すと、選んだ点のうち向きを持つ点（腰・頭・手・足）が全部、向きも固定されていたのを直した。向きを固定するのは、もともと向きを固定していた点だけです。骨も一緒に回すので、固定しない向きも体ごと回ります。

- 全身 IK の足の点を選んで Controller パネルの Reset を押しても、足が曲がったまま変わらなかったのを直した。固定していない点（足首の向き・踵・つま先など）は値を戻しても効かなかったので、選んだ点の骨の FK も基準へ戻します。

- 全身 IK の点をいくつか選んで動かすと、固定していない所が付いてこず姿勢が崩れていたのを直した。腰の点も選んでいれば腰も一緒に動くので、全部の点を選んで動かすと体がそのまま動きます。

- 胸の点を Pin にしていると、胸の前の点（引く強さ 0）を動かしても胸が回らなかったのを直した。胸の点を中心に、胸の点の位置を変えずに回ります。

- 全身 IK の点をいくつか選んで回すと、体ごと大きく回す形に届かず、ねじれていたのを直した。選んだ点のいちばん根の方の骨も一緒に回すので、全部の点を選んで回すと体がそのまま回ります。

- 全身 IK の点を回転のギズモで回すと、ドラッグの間にねじれが積み上がり、少しずつ回すほど体がねじれていたのを直した。ドラッグの間は始めの姿勢から回し直すので、細かく回しても一度に回したのと同じ姿勢になります。

- 書き出し先（✏）を Override の段へ移すと、つかむ段（✋）まで Override へ移り、全身 IK のハンドルが消えていた。全身 IK や表示の骨をつかんでいるときは、つかむ段をそのまま残します。

- Override の段（Additive）を重ねると、差分が前のフレームの値に積み重なることがあった。元の値と同じ一定のカーブを Unity が当てないため、操作値が前の値のまま残っていた。

- Override の統合で、キーを間引くたびにずれが積み重なり、元の形から 2° ほどずれることがあった。

- Override の段が効いていると、任意のプロパティで動かした Transform の値（武器の握りなど）が、編集用の体の値へ戻っていた。

- PoseBank のパネルだけ、窓の外へはみ出しても窓の中へ戻らなかったのを直した。

- Properties・Stacker のパネルが作り直されると、更新の処理が重ねて登録されていたのを直した。

- Motion Scene でメッシュを押したとき、キーの自動追加が切でも今のフレームにキーの無い骨を選べていたのを直した。表示域のクリックと同じく選びません。

- 表示域でハンドルや全身 IK の点にマウスを乗せても、止めてしばらくしないと強調されなかったのを直した。動かしている間もすぐ強調します。

- 全身 IK で膝と足首を両方固定しているとき、腰を動かすと足首まで動いていたのを直した。

- 全身 IK の点を基準姿勢へ戻すと、しゃがんだ姿勢などで体から離れた所へ飛んでいたのを直した。

- つかむ段が全身 IK のとき、指など点の無い骨の FK のハンドルが隠れて動かせなかったのを直した。出す骨はリグ定義の `fullBodyHandle` で決めます。

- 全身 IK で足を固定して腰を後ろへ引くと、脚が伸びきった所から上半身が大きく倒れこんでいたのを直した。腰は点に届き、上半身はまっすぐなままで、脚が届かない分は足に残ります。

- 全身 IK の点を親と子でまとめて選んで（Ctrl で子階層を選ぶなど）動かすと、子の点まで全部 Pin になっていたのを直した。子の Free の点は Free のまま体に付いて動き、つかんだ親だけが Pin になります。子の Pin・Locked の点は今までどおり一緒に動きます。

- タイムラインの Reset で姿勢を基準へ戻しても、全身 IK の点が元の場所に固定されたまま残っていたのを直した。戻した点の値（固定を外した値）もキーに打ちます。

- 全身 IK の点を選んで姿勢をコピーし、別のフレームへ貼り付けると、点だけが写って骨は貼り先の姿勢のまま残っていたのを直した。点を選ぶと、その点に関する骨（点の無い肩・指などはいちばん近い親の点の骨に含める）も写すので、全部の点を選べば全身の姿勢を写せます。

### Removed

- 既定のリグ定義から、膝・肘の Pole（`KneePole`・`ElbowPole`）を外した。膝・肘の向きは膝・肘の点で決めます。引く強さ 0 の点を Pole として解く仕組みは残っているので、要るときはリグ定義に点を足せます。今までのクリップの Pole のキーは当たらなくなります。

- 2 本骨 IK と足の転がし（roll / bank / twist）を削除した。手足は全身 IK で動かします。リグ定義の解き方の選択（`solver`）・IK の組（`ikChains`）・足の支点、Controller パネルの Pole と足の角度、ショートカット `Spinner Toggle Pole` も無くなりました。`Controls/IK` のキーを持つクリップのキーは当たりません。

- どこからも使っていなかった public API を外した。`TrackGUI`、`GLDraw.sceneGUIMaterial` と Scene GUI のシェーダ、`PreviewWindow` の `SetLayerParameter`・`orbitCamera`・`MovePickerSelection`・`BakeHumanoid`・`GetBakeProblem`・`GetMirrorTarget`・`MirrorSpinValues`、`PreviewStage` の `scene`・`contexts`、`IEditorHost.currentFrame`、`Clock` の `masterRate`・`speed`、`ContextHooks.hooks`、`LogSlider.value`、`PoseHandleUtility` の `isMouseOver`・`IsSelectedController`・`IsFocusedController`・`JointHandle`・`BoneHandle`（`Do` の付く版は残す）、`GeometryMath.GetDistanceRayToDot`、`AxisSlider.RaycastHitToJoint`、`ReverseFoot.SetPivot`、`ClipSampler.isValid`、`CurveWriter` の `clip`・`frame`・`count`、`RigProxies` の `Weight.rigName`・`Source.rigName`、`HumanoidGoals` の `bodyPosition`・`bodyRotation`・`humanScale`、`HumanoidMirror` の `Mirror`・`MirrorPosition` です。`PreviewStage.StripPolicy` と `ShortcutTooltip.Format` は private にしました。
