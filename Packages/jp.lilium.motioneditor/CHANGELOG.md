## [0.2.0] - 2026-10-26
<!-- changelog-sha: 6ab3ad6bed0a922c5a4e87da6cacc91aea762613 -->

### Added

- 全身 IK の点に、床との当たりに使う球の半径（`radius`）を追加。標準の定義では足裏の点に入っています。焼いた Humanoid 版は一度焼き直しが要ります。

- Floor Clamp で足の点を動かすと、足を硬い箱として床に押し当てるように。床に当たった所を支点に転がり、床に潜りません。

- Override の段にマスク（Channel Mask）を付けられるように。`Create > Lilium Motion Editor > Channel Mask` で作ります。

- 任意のプロパティ（ブレンドシェイプ・表示の ON/OFF・コンポーネントの値）を Override の段で重ねられるように。

- マスクのインスペクタに Avatar Mask の読み込み・書き出しを追加。

- 既定のマスク（Body・Upper Body・Hands・Face）を同梱。

- 窓を開かずに姿勢を作ってキーを打つ `PoseSession` を追加。スクリプトや AI から使う口です。

- 全身 IK の点で姿勢を JSON に読み書きする `PoseDocument` を追加。

- モーションの検査 `MotionLint` と Lint パネルを追加。足の滑り・床へのめり込み・跳ねなどを、フレームの範囲つきで出します。

- JSON の要求でモーションエディタを動かす `MotionEditorCommands` を追加。Unity CLI の `motion_*` コマンドからも呼べます。

- 姿勢を 4 方向から画像に書き出す `PoseCapture` を追加。

- 外で作った Humanoid のクリップを Override として取り込めるように。

- サイクルキーを追加。最後のキーを先頭のキーと同じ姿勢に保ち、ループの継ぎ目で止まりません。

- 全身 IK の足の点を、足首・踵・足裏の中心・小指側・つま先の先の 5 点に。

- 全身 IK の点に「引く強さ」（`pullStrength`）を追加。0 の点はほかの骨を引かず、骨を向けるだけになります。

- リグ定義の点に、線でつなぐ相手（`link`）を追加。

- Controller パネルに Reset ボタンを追加。

- 全身 IK の点をつなぐ線を押して、その骨を FK で動かせるように。

- 表示域で、マウスを乗せた骨や IK を強調するように。

- Controller パネルに Floor Clamp を追加。全身 IK の点や足を、床より下へ潜らせません。

- 表示域で、Shift で選択に足し、Ctrl で子階層をまとめて選べるように。

- 全身 IK の点に、ずれの向きを混ぜる相手の骨（`blendBone`）と割合（`blend`）を追加。

- Ctrl+A で、今つかめる物を全部選べるように。

- リグエディタの窓を追加。リグ定義の制御点を一覧から選び、数値で直せます。

- 全身 IK の既定の点に、お腹の点（`Stomach`）を追加。

- Unity CLI のコマンドを追加（`motion_read_motion`・`motion_write_motion`・`motion_sample`・`motion_delete_keys`・`motion_undo`・`motion_read_hand`・`motion_write_hand`）。

- 外部の骨格（External Skeleton）と BVH の読み書きを追加。キーの姿勢を BVH へ書き出し、BVH を Override として取り込めます。

- キーの間の補間を、区間ごとに曲線・リニア・ステップ・AI から選べるように。タイムラインのキーの間の矢印を右クリックして選びます。

- タイムラインに補間の表示の切り替えを追加。切ると、次のキーまで前のキーの姿勢のまま見せます（コマ送り）。

- サンプル Kimodo (optional) を追加。NVIDIA の Kimodo で、キーの間の動きを文章から作れます。Kimodo は同梱していません。

### Changed

- Motion Editor の窓のパネルの既定の置き場所を変更。初めて開く窓だけに効きます。

- ツールバーに入れた Overlay メニューを、目のアイコンのボタン 1 つに畳むように。

- 前のキー・次のキーのショートカットの既定を A・D に変更（以前は , と .）。

- 姿勢のコピー・貼り付けを Ctrl+C / Ctrl+V に変更（以前は C / V）。

- 全身 IK の点を 1 つ選んで回すと、その骨より先の Pin・Locked の点も一緒に回るように。

- リグ定義の全身 IK の点の置き場所を、1 つの式で決めるように変更。既定の点の名前と場所は変わりません。

- つま先の骨が無いキャラには足の点を、指の骨が無いキャラには手のひらの点を作らないように。

- 顔の前の点の高さを、目の骨から求めるように。

- 肘・膝の曲がる向きと接地の点を、リグ定義に持つように変更。焼いた Humanoid 版は一度焼き直しが要ります。

- リグ定義の版と、古い版の定義の読み替えを廃止。古い定義は、インスペクタの「既定に戻す」で作り直してください。

- Transform パネルの名前を Controller に変更。

- Stacker の Loop のトグルを、サイクルキーの付け外しに変更。

- 既定の定義で、向きの点（`HipsDirection` など）の引く強さを 0 に変更。向きの点を固定してあるクリップは、解いた姿勢が変わります。

- 顔の前の点（`HeadDirection`）を目の高さに変更。

- 踵の点を足首の真下へ移動。

- 全身 IK の点の枠選択で、選択に足すのを Shift だけに変更。

- パネルのアクセントの色を、エディタのテーマの選択の色に変更。

- Controller パネルの Mirror ボタンを廃止。

- Layers の段の間の矢印を Material Icons に変更。

- タイムラインの全身 IK の点のトラックで、キーの間の矢印を点の状態（Free / Pin / Locked）の色に。

- 背骨の全身 IK の点を、胸の点（`Chest`）1 つに統合。背骨の点のキーは当たらなくなります。

- タイムラインの Auto Key の切り替えを、アイコンのボタンに変更。

- `PreviewWindow.EndCurveEdit` を `AfterClipEdit` に名前変更。`HumanoidOutput` のオーバーロードの整理と、`BankEntry` への統合も含みます。

### Fixed

- 頭の向きを固定したフレームで、顔の前の点を動かしても頭が向かない不具合を修正。

- 全身 IK の点を複数選んで回すと、向きを持つ点が全部向きも固定される不具合を修正。

- 足の点を選んで Reset を押しても、足が曲がったまま戻らない不具合を修正。

- 全身 IK の点を複数選んで動かすと、姿勢が崩れる不具合を修正。

- 胸の点を Pin にしていると、胸の前の点を動かしても胸が回らない不具合を修正。

- 全身 IK の点を複数選んで回すと、体がねじれる不具合を修正。

- 回転のギズモで回すと、ドラッグの間にねじれが積み上がる不具合を修正。

- 書き出し先を Override の段へ移すと、全身 IK のハンドルが消える不具合を修正。

- Additive の段の差分が、前のフレームの値に積み重なることがある不具合を修正。

- Override の統合で、キーを間引くたびにずれが積み重なる不具合を修正。

- Override の段が効いていると、任意のプロパティで動かした Transform の値が戻る不具合を修正。

- PoseBank パネルが窓の外へはみ出したまま戻らない不具合を修正。

- Properties・Stacker パネルを作り直すと、更新の処理が重ねて登録される不具合を修正。

- Motion Scene でメッシュを押すと、Auto Key が切でもキーの無い骨を選べてしまう不具合を修正。

- マウスを止めてしばらくしないと、ハンドルが強調されない不具合を修正。

- 膝と足首を固定しているとき、腰を動かすと足首まで動く不具合を修正。

- 全身 IK の点を基準姿勢へ戻すと、体から離れた所へ飛ぶ不具合を修正。

- つかむ段が全身 IK のとき、指など点の無い骨の FK ハンドルが出ない不具合を修正。出す骨はリグ定義の `fullBodyHandle` で決めます。

- 足を固定して腰を後ろへ引くと、上半身が大きく倒れこむ不具合を修正。

- 親と子の点をまとめて動かすと、子の点まで Pin になる不具合を修正。

- タイムラインの Reset で、全身 IK の点が元の場所に固定されたまま残る不具合を修正。

- 全身 IK の点を選んでコピー・貼り付けすると、骨が写らない不具合を修正。

### Removed

- ツールバー Context の、演出の prefab を選ぶ欄を廃止。

- 既定のリグ定義から膝・肘の Pole を削除。今までのクリップの Pole のキーは当たらなくなります。

- 2 本骨 IK と足の転がしを削除。手足は全身 IK で動かします。`Controls/IK` のキーは当たらなくなります。

- 使われていない public API を削除（`TrackGUI`、`PreviewWindow.BakeHumanoid` など）。

## [0.1.1-exp.1] - 2026-10-04
<!-- changelog-sha: e5696fb037f9e7db9054e011600b7974bc3b015c -->

### Added

- **画面の文字を英語と日本語に対応した。** 言語は `Preferences > Lilium Motion Editor` の Language で選ぶ（この PC の設定。既定は OS の言語で、日本語なら日本語・それ以外は英語）。切り替えるとスクリプトを読み直して窓を作り直す。文字はキーで引き、`Editor/Localization/MotionEditorLocales/en.json`・`ja.json` に持つ（今の言語に無ければ英語、それも無ければキーのまま）。インスペクタの説明（持ち替えの定義・キャラの設定の `[Tooltip]`）は英語にした（パッケージの依存は増やしていない）

- 今のフレームの全部にキーを打つ Key All（Stacker のボタン）をショートカット K で押せるようにした（モーションエディタの窓と Motion Editor In Scene。Shortcut Manager の `Lilium Motion Editor/Key All`）

### Changed

- Window メニューの項目を `Window > Lilium Motion Editor` の下にまとめた（`Motion Editor` / `Motion Editor In Scene (Experimental)`。以前は `Window > Motion Editor (Preview)` / `Window > Motion Editor (Scene)`）

- タイムラインのキーの箱から通し番号を外し、箱の幅をそろえた。キーの間のフレーム数は、間の線を切ってその中に出す

- タイムラインの右クリックメニューから、キーのコピー・貼り付けと「Go to Frame」「Delete Key」を外した。コピー・貼り付けは Ctrl+C / Ctrl+V、押したキーは選ばれるので消すのは「キーを削除」で行う

### Removed

- 使っていない古いショートカットの説明の窓 `HelpWindow` を削除した
