# Change Log

## [Unreleased]

- クラス名の頭の `Mkt` を外した（名前空間 `Lilium` で分けているので要らない）。インターフェイスは `IMkt...` → `I...`（差し込み口の `IContextHook` / `IHumanoidBakeHook` / `IPoseGraphHook` など）、属性は `[MktPoseLayer]` → `[PoseLayer]`・`[MktLayerParameter]` → `[LayerParameter]`・`[MktLayerInverse]` → `[LayerInverse]`。外すと Unity の型とぶつかるものなどは別の名前にした: `MktRigDefinition` → `EditRigDefinition`、`MktEditorUtility` → `ClipKeyUtility`、`MktHandles` → `PoseHandles`、`MktHandleUtility` → `PoseHandleUtility`、`MktSlider` → `AxisSlider`、`MktSettings` → `SettingsLookup`、`MktUserLayer` → `UserComponentLayer`。ファイル名も合わせた（.meta の GUID は変えていないので、アセットからの参照は切れない）。差し込み口・属性を使っている側は名前を直す必要がある
- 新しく作るリグ定義（パッケージの既定の定義・Create で作る定義・インスペクタの Reset）の解き方の既定を全身 IK（`RigSolver.FullBodyIk`）にした（`EditRigDefinition.SetDefault`）。`solver` の項目が無い古い定義アセットは、今までどおり 2 本骨 IK で読む
- ポーズのコピー（C・タイムラインの上端の段の Copy）で、骨・全身 IK の点などを選んでいれば選んだ物（複数可）のポーズだけをコピーするようにした。何も選んでいなければ今までどおり全体。貼り付け（V）はコピーした物のカーブにだけキーを打ち、ほかの骨は変えない（`MktPoseClipboard.Copy` に写すカーブの絞り込みを追加）
- `GLDraw` から、外から持ってきたコード（線・箱・ベジェの描画と矩形での切り取り。`DrawLine` / `DrawBox` / `DrawRoundedBox` / `DrawConnectingCurve` / `DrawBezier` / `BeginGroup` / `EndGroup`）を削除した。出どころのライセンスがはっきりしない（一部は CC BY-SA）ので、MIT のパッケージには入れられない。パッケージでは使っておらず、材質（`lineMaterial` / `sceneGUIMaterial`）と `Initialize` だけを残す
- 使っていない `GeometryMath.RaycastToCylinder` と `Cylinder` を削除した（ブログのコードを移したもので、出どころのライセンスがはっきりしない）
- サンプル（Demo）に手の形の姿勢 8 つ（Fist・Flat・Grip・Open・Peace・Point・Relaxed・ThumbsUp）を追加（`Samples~/Demo/Poses`）。Humanoid の指の muscle の値なので、指の骨のある Humanoid のキャラならそのまま貼れる。PoseBank に出すには、インポートした `Demo/Poses` のフォルダをプロジェクト設定の PoseBank Folders に足す
- Transform パネルの Move / Rot / Scale（Spinner とビューのギズモのモード）のショートカットを、Unity と同じ W / E / R にした（以前は I / O / P）。プレビュー窓と Motion Scene で、窓にフォーカスがある間は Unity の Tools/Move・Rotate・Scale より優先される。R とぶつかる全身 IK の点の固定の付け外し（Toggle Point Lock）は L にした。Shortcut Manager で割り当てを変えていた場合はそのまま
- Auto Key 切のときは、全身 IK の点も、今のフレームにキーがあるときしか動かせないようにした。以前は切でもギズモ・Spinner で点を動かせ、離すとキーの無いフレームにも全身のキーを打っていた。点の固定の付け外し（右クリック・Free / Pin / Lock・L）は明示的な操作なので、今までどおり切でも打つ
- 回転ハンドルの X・Y・Z の弧の両端にあった矢（円錐）をなくし、平らな弧だけにした（`MktDisc`）
- タイムラインの上端の段に「Auto Key」のスイッチを追加（プロジェクト設定の Auto Key と同じ値。どちらで変えても表示が合う）。プロジェクト設定を保存したときのイベント `MktProjectSettings.changed` を追加
- 全身 IK で、腰を位置だけ固定して足首を持ち上げる（まっすぐな脚の足を上げる・つま先の先を固定してかかとを上げる）と、腰が回って上半身が傾いていたのを修正。肘・膝を、届くのに要るだけ直に曲げる拘束を足した。つま先の骨があるキャラで、つま先の先を固定して足首を動かすと、つま先の先が数 cm 外れていたのも直った
- Unity 6.0 のプレビュー窓で、骨や全身 IK の点がキャラの絵からずれて描かれ（下の方ほど大きく）、クリックしても押した点が選べなかった（別の点やメッシュの骨が選ばれた）のを修正。`Handles.SetCamera` が出力先を持つハンドル用カメラの表示域を入れていなかったので、窓が自分で入れる
- 起動して初めて全身 IK を使うとき、Burst のコンパイルが終わるまでエディタが止まっていたのを修正（Unity 6.0 の Burst 1.8 では 1 分以上）。ジョブの `CompileSynchronously` をやめ、コンパイルが済むまではマネージドで解く
- サンプルの説明からモデル名を外した
- サンプルに Quaternius の Universal Base Characters（CC0）の男女 2 体を追加（`Samples~/Demo/Sample/Quaternius`。Humanoid・指の骨あり）
- キャラの向き（Facing）を削除した。窓の Context の向きの選択、プロジェクト設定・キャラの設定の `Facing`、差し込み口 `IMktFacingHook` / `MktFacingHooks` / `MktFacing` を削除。窓にはいつも prefab のままの向きで置き、演出も回さない。`MktPreviewStage` と `MktSettings.Create` の引数から向きを外した
- 既定のリグ定義をパッケージのアセット（`Editor/Rig/Default Rig Definition.asset`、`MktRigDefinition.packageDefault`）にした。プロジェクト設定の Rig Definition が空ならこれを使い、欄にもこれを出す。別の定義を入れると全キャラの既定になる（`MktProjectSettings.defaultRigDefinition`）。キャラの設定で上書きにしていて欄が空のときも、プロジェクト設定の定義を使う（以前はコードの既定）。パッケージの既定を開くと、直すなら Create で作るよう注意を出す

- プレビュー窓のタイムラインを作り直した（`MktPreviewWindow.Timeline.cs`）。再生ボタンの段（前のキー・前のフレーム・再生・次のフレーム・次のキー）、黒い目盛り、キーのトラック（クリップ全体＋選んだ骨ごと）。キーは通し番号の箱で今のフレームのキーは白、キーの間は両矢印とフレーム数で結ぶ。ホイールで横の拡大縮小、中ボタン（Alt+左）ドラッグで横移動、Fit でキーの範囲に合わせる。キーの箱はクリックでそのフレームへ、ドラッグで移動（Shift で複製）、トラックの外へ出して離すと削除、右クリックでメニュー。骨のトラックの操作はその骨のカーブだけに効く。`MktControllerEditor.CollectKeyedTransforms` を追加、`MktEditorUtility` のキー操作にカーブの絞り込みを追加。ショートカットに前後のキー（, / .）を追加

- プレビュー窓に Picker のオーバーレイ（`MktPickerOverlay`）を追加した。骨と手足の IK が骨のつながりの順に字下げ付きで並び、クリックで選べる。一覧と窓（ハンドル・Spinner）の選択は一致する。一覧の上で ↑↓ で前後の骨へ、Home / End で先頭・末尾へ移る（一覧にフォーカスが無いときの Home / End は今までどおりフレームの移動。End は最後のキーへ）
- プレビュー窓で、ハンドルに当たらない左クリックがメッシュを指していたら、その場所を一番動かしている骨を選ぶようにした（今までは選択が外れるだけ）。今の姿勢でメッシュを焼いて（`BakeMesh`）三角形と交差させ、当たった面の頂点のウェイトが一番大きい骨を採る。骨を持たないメッシュ（武器など）は付いている骨をたどる。前腕や太ももをクリックするとその手足の IK が選ばれる
- プレビュー窓に Spinner のオーバーレイ（`MktSpinnerOverlay`）を追加した。丸い操作盤の X（赤）・Y（緑）・Z（青）の扇形を上下にドラッグすると、選んでいる骨のその軸が増減する（上で増える）。Move / Rot / Scale を切り替えられ（I / O / P）、回転の中央と中ボタンのドラッグは見ている向きの軸まわり（多軸）、大きさの中央は全軸。IK を選んでいるときは目標を動かし、Pole（U）で肘・膝の向きに切り替える。Shift で細かく、Ctrl できりのいい値（1cm / 5° / 0.05）に止まる。描画は `Painter2D`、操作はポインタイベントを自前で処理する
- 骨の位置とスケールのカーブを、Spinner で動かしたときに作るようにした（既定のボーンコントローラーは回転しかキーを持たない）。一度できたカーブは、以降の姿勢のキーでも一緒に打つ。`MktEditorUtility.MakeScaleCurves` / `HasTransformCurve` を追加
- 骨・関節のハンドルを離してもつかみ（`GUIUtility.hotControl`）が残り、他の操作（プレビュー窓のタイムラインなど）が効かなくなるのを修正。ねじり（ホイール）は、選んでいる骨の上でホイールを回したときに効く
- Paste Pose が何も貼らなかったのを修正（貼り先のカーブを探す条件が、コピー元ではなく空のバインディングと比べていた）。同じフレームにあるキーは上書きする
- レイヤースタック（`MktPoseStack` / `MktPoseLayer`）と Layers のオーバーレイを追加した。段は自動で並び、表示・書き出し先・つかむ段を選べる。ゲーム側の段は `[MktPoseLayer]` 属性で足せる
- **編集用リグに置き換えた**（S1）。プレビュー窓はキャラの骨を複製した「編集用の体」（`MktEditingRig`）を作り、固定名のコントロール（`Controls/FK/<骨>`・`Controls/IK/<組>/Target|Hint`・`Controls/Extra/<名前>`）を動かす。クリップにはコントロールの値だけを保存し、骨のカーブは持たない

  - つかむ対象の共通の形 `MktPoseTarget`。窓・Spinner・Picker・タイムライン・Copy/Paste/Reset はこれだけを通す。IK の組の骨をつかむと FK へ、目標をつかむと IK へ、見た目を保って切り替わる
  - キーの書き込みを `MktCurveWriter` に集めた（Undo・まとめ書き・回転の符号合わせ・数値のキー）。1 個目のキーのときに時刻 -1 のキーを足していたのを削除
  - クリップはグラフで編集用の体へ流す（`MktClipSampler`。数値のカーブも当たる）
  - 編集用クリップの見分け方 `MktEditingClip`（規約は `*.rig.anim`）。コントロールのカーブが無いクリップは編集できないとして理由を大きく出す。コントロール以外のカーブが残っていれば警告し、ツールバーの Clean で消せる
  - ゲームの Animation Rigging の値（Rig と拘束の重み・Rig の下のターゲット）を `Controls/Game/<Rig 名>` の代理に持つ（`MktRigProxies`、`MktRigLayerProxy` / `MktRigConstraintProxy`）。ゲーム prefab のパスとの対応表も作る。重みは Rig Values のオーバーレイで動かす
- 窓の時計 `MktClock` を追加した。姿勢は秒のまま当て、キーは近いフレームへ丸めて打つ（格子から外れているときは画面に出す）。再生中につかむと止め、離すと続きから再生する
- **旧コードを削除した**: `MktAnimationController` / `MktBoneController` / `MktTwoBoneIKSolver` / `MktTwoBoneIKSolverController` とそのエディタ、Scene ビュー版の窓 `MktMotionEditorWindow`、`AnimationEditorAccessor`、ランタイムの `Mikoto.Utility` / `MktUtility`、`MktEditorUtility` の旧書き込み口（`SetKey` / `Make*Curves` など）。`MktGeometryMath` は Editor へ移した。`TrackGUI` / `GLDraw` / `MktHelpWindow` は利用者がいるので残す
