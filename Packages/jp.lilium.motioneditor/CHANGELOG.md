# Changelog

## [Unreleased]

### Added

- 全身 IK の点に、動かせない点（`passive`）を置けるように。選べるが動かせず、キーも持ちません。付け根から離して置くと、骨はその点と付け根を結ぶ軸まわりにだけ回ります。焼いた Humanoid 版は一度焼き直しが要ります。

- Kimodo サンプルで、動きの説明とシードをクリップごとに持てるように。シードを固定すると、同じ動きを作り直せます。

### Changed

- 全身 IK の点の「引く強さ」（`pullStrength`）を「重さ」（`weight`）に変更。0 の点を動かすと、0 の点は Free でも Pin でも引かれ、1 の点とその向こうの点は動きません。1 の点を動かすと、0 の Pin の点は Free と同じに引かれ、1 の Pin の点は届く間はその場に留まり、届かなければ付いて動きます（Lock の点は動きません）。骨の付け根の点（膝・腰など）も 0 にできます。前の名前で保存した定義もそのまま読めます。

- 重さ 0 の全身 IK の点を、小さい丸で描くように。

- 全身 IK の点を動かしている間、ほかの Pin の点を動かす前の場所でなく今の骨の場所に描くように。

### Fixed

- キーを打った後に Ctrl+Z を続けて押すと、エディタが長く止まる不具合を修正。

- Kimodo の動きの取り込みが、直前の操作と同じ Undo にまとまる不具合を修正。

- ツールバーから開いた Kimodo のパネルの高さが足りず、下が切れる不具合を修正。

- 手首・足首を位置だけで固定しているとき、肘・膝の点を横へ動かしてもほとんど付いてこない不具合を修正。

- 背骨を丸めたキーで首を持ち上げても、体がまっすぐにならない不具合を修正。

## [0.2.0] - 2026-10-26
<!-- changelog-sha: 6ab3ad6bed0a922c5a4e87da6cacc91aea762613 -->

### Added

- 全身 IK の点に、床との当たりの大きさを持たせられるように。焼いた Humanoid 版は一度焼き直しが要ります。

- Floor Clamp で足の点を動かすと、足が床に潜らず床に沿って転がるように。

- Override の段にマスク（Channel Mask）を付けられるように。

- ブレンドシェイプや表示の ON/OFF など任意のプロパティを、Override の段で重ねられるように。

- マスクを Avatar Mask から読み込み・書き出しできるように。

- 既定のマスクを同梱。

- 窓を開かずに姿勢を作ってキーを打つ `PoseSession` を追加。

- 全身 IK の点で姿勢を JSON に読み書きする `PoseDocument` を追加。

- モーションの検査 `MotionLint` と Lint パネルを追加。足の滑りや床へのめり込みなどを見つけます。

- JSON の要求でモーションエディタを動かす `MotionEditorCommands` を追加。Unity CLI からも呼べます。

- 姿勢を画像に書き出す `PoseCapture` を追加。

- 外で作った Humanoid のクリップを Override として取り込めるように。

- サイクルキーを追加。ループの継ぎ目で動きが止まらないようにします。

- 全身 IK の足の点を増やし、踵やつま先も動かせるように。

- 全身 IK の点に「引く強さ」を追加。0 にすると、ほかの骨を引かずに骨を向けるだけになります。

- リグ定義で、点どうしを線でつなげるように。

- Controller パネルに Reset ボタンを追加。

- 全身 IK の点をつなぐ線を押して、その骨を FK で動かせるように。

- 表示域で、マウスを乗せた骨や IK を強調するように。

- Controller パネルに Floor Clamp を追加。点や足が床に潜らないようにします。

- 表示域で、Shift で選択に足し、Ctrl で子階層をまとめて選べるように。

- 全身 IK の点に、ほかの骨の向きを混ぜられるように。

- Ctrl+A で、今つかめる物を全部選べるように。

- リグエディタの窓を追加。リグ定義の制御点を一覧から選んで数値で直せます。

- 全身 IK の既定の点に、お腹の点を追加。

- Unity CLI のコマンドを追加（モーションや手の形の読み書き、キーの削除、Undo など）。

- 外部の骨格（External Skeleton）と BVH の読み書きを追加。BVH を Override として取り込めます。

- キーの間の補間を、区間ごとに曲線・リニア・ステップ・AI から選べるように。

- タイムラインで補間の表示を切り替えられるように。切ると、キーの姿勢だけをコマ送りで見せます。

- サンプル Kimodo (optional) を追加。キーの間の動きを文章から作れます。Kimodo 本体は同梱していません。

### Changed

- Motion Editor の窓のパネルの既定の置き場所を変更。初めて開く窓だけに効きます。

- ツールバーに入れた Overlay メニューを、目のアイコンのボタン 1 つに畳むように。

- 前のキー・次のキーのショートカットを A・D に変更。

- 姿勢のコピー・貼り付けを Ctrl+C / Ctrl+V に変更。

- 全身 IK の点を回すと、その先の固定した点も一緒に回るように。

- リグ定義の全身 IK の点の置き場所の決め方を整理。既定の点は変わりません。

- つま先の骨が無いキャラには足の点を、指の骨が無いキャラには手のひらの点を作らないように。

- 顔の前の点を目の高さに変更。

- 肘・膝の曲がる向きと接地の点を、リグ定義に持つように変更。焼いた Humanoid 版は一度焼き直しが要ります。

- リグ定義の古い版の読み替えを廃止。古い定義は、インスペクタの「既定に戻す」で作り直してください。

- Transform パネルの名前を Controller に変更。

- Stacker の Loop のトグルを、サイクルキーの付け外しに変更。

- 既定の定義で、向きの点の引く強さを 0 に変更。向きを固定してあるクリップは姿勢が変わります。

- 踵の点を足首の真下へ移動。

- 全身 IK の点の枠選択で、選択に足すのを Shift だけに変更。

- パネルのアクセントの色を、エディタのテーマの選択の色に変更。

- Controller パネルの Mirror ボタンを廃止。

- Layers の段の間の矢印のアイコンを変更。

- タイムラインの全身 IK の点のキーの間の矢印を、点の状態の色で描くように。

- 背骨の全身 IK の点を、胸の点 1 つに統合。背骨の点のキーは当たらなくなります。

- タイムラインの Auto Key の切り替えを、アイコンのボタンに変更。

- 一部の public API の名前と形を変更（`PreviewWindow.EndCurveEdit` → `AfterClipEdit` など）。

### Fixed

- 頭の向きを固定したフレームで、顔の前の点を動かしても頭が向かない不具合を修正。

- 全身 IK の点を複数選んで回すと、向きを持つ点が全部向きも固定される不具合を修正。

- 足の点を選んで Reset を押しても、足が曲がったまま戻らない不具合を修正。

- 全身 IK の点を複数選んで動かすと、姿勢が崩れる不具合を修正。

- 胸の点を Pin にしていると、胸の前の点を動かしても胸が回らない不具合を修正。

- 全身 IK の点を複数選んで回すと、体がねじれる不具合を修正。

- 回転のギズモで回すと、ドラッグの間にねじれが積み上がる不具合を修正。

- 書き出し先を Override の段へ移すと、全身 IK のハンドルが消える不具合を修正。

- Additive の段の差分が、前のフレームの値に積み重なることがある不具合を修正。

- Override の統合で、キーを間引くたびにずれが積み重なる不具合を修正。

- Override の段が効いていると、任意のプロパティで動かした Transform の値が戻る不具合を修正。

- PoseBank パネルが窓の外へはみ出したまま戻らない不具合を修正。

- Properties・Stacker パネルを作り直すと、更新の処理が重ねて登録される不具合を修正。

- Motion Scene でメッシュを押すと、Auto Key が切でもキーの無い骨を選べてしまう不具合を修正。

- マウスを止めてしばらくしないと、ハンドルが強調されない不具合を修正。

- 膝と足首を固定しているとき、腰を動かすと足首まで動く不具合を修正。

- 全身 IK の点を基準姿勢へ戻すと、体から離れた所へ飛ぶ不具合を修正。

- つかむ段が全身 IK のとき、指など点の無い骨の FK ハンドルが出ない不具合を修正。

- 足を固定して腰を後ろへ引くと、上半身が大きく倒れこむ不具合を修正。

- 親と子の点をまとめて動かすと、子の点まで Pin になる不具合を修正。

- タイムラインの Reset で、全身 IK の点が元の場所に固定されたまま残る不具合を修正。

- 全身 IK の点を選んでコピー・貼り付けすると、骨が写らない不具合を修正。

### Removed

- ツールバー Context の、演出の prefab を選ぶ欄を削除。

- 既定のリグ定義から膝・肘の Pole を削除。今までのクリップの Pole のキーは当たらなくなります。

- 2 本骨 IK と足の転がしを削除。手足は全身 IK で動かします。

- 使われていない public API を削除。
